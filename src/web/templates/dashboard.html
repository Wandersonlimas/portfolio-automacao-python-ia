Método de cálculo

denominadores documentados
  • Exceção: pedidos com ≥1 motivo / pedidos válidos
  • SLA: despachos em até 48 h / pedidos expedidos e confirmados
  • Conciliação: confirmados com valor pago igual ao pedido
  • Receita conciliada: soma dos pedidos confirmados sem divergência
  • Rejeição: registros brutos descartados pelo ETL
  • Recortes: todos os KPIs são recalculados após os filtros

Limites e honestidade técnica

informações indispensáveis para avaliação

Este projeto não recebe dados de produção nem consome APIs corporativas. A base sintética é gerada com semente fixa e representa um cenário hipotético. Os diagnósticos exibidos são regras de negócio executadas localmente. O módulo de IA é um exemplo de integração opt-in, dependente de configuração e credenciais externas, não usado no painel demonstrativo.
